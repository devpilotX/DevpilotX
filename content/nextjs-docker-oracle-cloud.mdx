Oracle Cloud's free tier gives you a real Linux machine, which makes it a good place to host side projects. This is the checklist I follow when I put a Next.js app on one of those instances with Docker and Nginx.

## 1. Build a small image

Set `output: "standalone"` in `next.config.mjs`. Next.js then copies only the files the server needs into `.next/standalone`, which keeps the image small.

```dockerfile title="Dockerfile"
FROM node:22-alpine AS build
WORKDIR /app
COPY package.json pnpm-lock.yaml ./
RUN corepack enable && pnpm install --frozen-lockfile
COPY . .
RUN pnpm build

FROM node:22-alpine
WORKDIR /app
ENV NODE_ENV=production
COPY --from=build /app/.next/standalone ./
COPY --from=build /app/.next/static ./.next/static
COPY --from=build /app/public ./public
EXPOSE 3000
CMD ["node", "server.js"]
```

The Ampere instances are ARM, so build the image on the server itself or use `docker buildx build --platform linux/arm64` on your laptop.

## 2. Open the ports twice

This is the step that confuses people. Traffic has to get through two firewalls.

1. **The VCN security list** in the Oracle console. Add ingress rules for TCP 80 and 443.
2. **iptables on the instance.** Oracle's Ubuntu images ship with rules that reject almost everything except SSH.

```bash
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 80 -j ACCEPT
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 443 -j ACCEPT
sudo netfilter-persistent save
```

If the site times out even though the container is running, check this first.

## 3. Run the container

```bash
docker run -d --name web --restart unless-stopped -p 127.0.0.1:3000:3000 my-app
```

Binding to `127.0.0.1` means the app is only reachable through Nginx, not straight from the internet on port 3000.

## 4. Put Nginx in front

```nginx title="/etc/nginx/sites-available/my-app"
server {
    server_name example.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

Enable the site, reload Nginx, then run `sudo certbot --nginx -d example.com` to get a free TLS certificate. Certbot also sets up automatic renewal.

## 5. Ship updates

Once this works, updating is only a few commands: pull the code, rebuild the image, and replace the container. A GitHub Actions job that SSHes into the server and runs them is a good next step.
